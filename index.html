Как установить

Скопируйте код кнопки и выберите платформу сайта. После публикации проверьте кнопку на домене, который указали в конструкторе.

Вставка в <head>

  1. Откройте HTML страницы или общий шаблон сайта. В CMS можно использовать поле для кода в <head>.
  2. Вставьте код виджета перед </head> или в выбранное поле. Сохраните и опубликуйте изменения.
index.html
<head>
  <!-- Вставьте код кнопки здесь -->
</head>

В WordPress можно использовать плагин WPCode и поле Code Snippets → Header & Footer → Header. На WordPress.com нужен тариф с поддержкой плагинов.

Справка WordPress.com

Блок T123 «HTML-код»

  1. В редакторе нужной страницы откройте Библиотека блоков → Другое и добавьте T123 «HTML-код».
  2. Откройте «Контент» блока, вставьте код виджета целиком, сохраните блок и опубликуйте страницу.

Код также можно вставить в поле «HTML-код для вставки внутрь head». Для одной страницы откройте Настройки страницы → Вставка кода, для всех — Настройки сайта → Ещё. Затем опубликуйте нужные страницы. На бесплатном тарифе T123 и вставка в <head> недоступны.

Пользовательский HTML

  1. Для всего сайта откройте Настройки сайта → HTML. Вставьте код в поле «Пользовательский HTML </head>» и опубликуйте все страницы.
  2. Для одной страницы добавьте блок Другое → HTML-код. Вставьте код в настройках блока и опубликуйте страницу.
Справка Craftum

Пользовательский код в панели Wix

  1. В панели управления откройте Настройки → Разработка и интеграции → Пользовательский код.
  2. Нажмите «Добавить код», вставьте фрагмент и выберите нужные страницы. В поле размещения выберите Body — конец и сохраните.

Нужен опубликованный сайт с подключённым доменом. Для установки на весь сайт выберите загрузку кода на каждой странице.

Справка Wix

Custom code в Webflow

  1. Для всего сайта откройте Site settings → Custom code → Head code. Для одной страницы выберите Page settings → Custom code → Inside <head> tag.
  2. Вставьте код виджета, сохраните настройки и опубликуйте сайт.

Для своего кода нужен активный Site plan или Workspace на тарифе Core, Growth, Agency либо Freelancer.

Вопросы и ответы

Как работает виджет, зачем нужна почта и как изменить кнопку после установки.

Кнопка действительно бесплатная?

Да. Вы можете создать кнопку бесплатно и без регистрации. На вашем сайте она будет отображаться без рекламы и логотипа JustButton.

Зачем подтверждать почту?

Одноразовый код помогает ограничить автоматическое создание виджетов. Адрес нужен для подтверждения и не попадает в код кнопки.

С какими сайтами работает виджет?

С сайтами, на которых можно добавить JavaScript. Для своего HTML и CMS подойдёт вставка в head, а для Tilda, Craftum, Wix и Webflow используйте инструкцию в разделе «Как установить».

Что увидит посетитель на телефоне?

Кнопка появится в правом нижнем углу. Отдельный отступ для телефона позволяет поднять её над нижним меню или баннером.

Можно изменить ссылку или положение кнопки?

Да. Создайте новую кнопку с нужными настройками и замените старый фрагмент кода на сайте.
